## 数据与行为细节

- `Plan.version` 为 `1.0`。Run 与 TaskSpec 沿用 6.4、6.5 的明确结构，不因 6.1 的概括文字额外增加 version 字段。
- 存储根目录采用 8.1 的 `backend/storage/`，6.6 的 `server/storage/` 视为逻辑示意。方案索引与运行快照结构保持不变。
- `props.name` 作为可选显示名称也保留在由清单生成的条件、延时和结束节点上，确保改名可以在画布和重新加载后显示；行为仍仅由其类型及 expression/wait 等既有属性决定。
- 名称长度按 Unicode 字符计数。文件大小按 UTF-8 字节，200KB 为 204800 字节。任务清单最多转换成 100 节点、200 边。
- 没有动作关键词且包含子条目的 Markdown 标题用作分组容器，列表或编号条目作为任务。命中动作关键词的父标题可成为节点，子条目依赖它。叙述段落、代码块不作为任务。
- 英文 Markdown 可以识别结构并生成普通任务，语义关键词仍以说明书中文规则为准。重复编号或未绑定条件的分支后缀返回 40003；缺一侧分支保留预览，生成/执行前提示修正。
- 自动条件默认引用 `passed`，后续独立条件使用 `passed_2` 等变量，前一个普通任务成功后输出对应变量。确认表可修改表达式与输出变量；不会推断真实认证业务。
- 清单取消勾选会跨过被省略条目，保留其上游依赖；删除条目时清理依赖。缺失分支或循环依赖会明确提示，不静默生成无法运行的图。
- 未指定任务耗时默认 800ms、重试 0、失败率 0，延时默认 1000ms。并发数限定为 1～100 的整数，默认 3。
- 表达式使用严格类型比较；未定义变量读取为 undefined，最终结果转为布尔值。禁止函数调用、赋值、属性访问和危险变量名。
- 条件分支以边信号区分“未激活”与“上游失败”，避免嵌套分支中未激活的汇聚点意外执行。continueOnError 只忽略失败，不激活未选择的条件分支。
- 停止时将未开始和仍在执行的节点统一标记 CANCELED，并取消等待，防止出现迟到的成功状态。重启服务后读取未结束的运行会标记为 FAILED，并记录服务重启原因。
- 完成运行通过保存的 runId 恢复，接口不新增运行列表端点。500ms 增量轮询只访问本地 API。
- 首次 npm 安装需要网络。完成依赖安装后，规则分解、画布编辑、模拟执行和持久化均可离线运行，不加载 CDN 字体或脚本。后续新增的可选 AI 分解需要访问配置的模型 API。


## 自然语言扩展约定

2026-11-17，用户确认新增与规则分解并行的自然语言入口，原先“无需外部服务或 API Key”的范围扩展为：规则路径继续离线，AI 路径接受联网和服务端 API Key。

- `backend/engine/decomposer.js` 的规则逻辑保持原样。新增 `POST /api/decompose-nl` 接收 `{text}`，成功封装与原接口相同，仍为 `{ok:true,taskSpec}`。
- TaskSpec 不增加字段、不替换字段名。任务字段继续使用 `key/name/type/dependsOn`，可选 `parallelGroup/branch/expression/output`。前端临时 `selected/removed` 不由模型返回。
- `detectedFormat` 维持 `markdown/numbered` 枚举。AI 输出采用 `numbered` 表示生成的编号任务结构，来源模式由对话框局部状态记录，界面显示“AI 分解结果”。这不代表用户输入本来具有编号格式。
- 不新增确认表或状态管理库。两条入口汇入同一结果处理、表格编辑、TaskSpec 转 Plan 和现有执行链路。条件分支继续使用字符串 `"true"/"false"`，并行关系须由实际依赖表达。
- 服务端新增 TaskSpec 校验，检查字段、类型、编号唯一性、依赖引用和循环；再用现有画布转换器及 R1～R8 校验生成图。校验过程不保存方案、不启动执行。
- 配置由 `LLM_API_KEY`、`LLM_BASE_URL` 和 `LLM_MODEL` 提供。根目录 `.env` 用于本地文件配置，进程环境变量优先。前端不可读取密钥，不使用 `VITE_` 前缀暴露配置。
- `GET /api/decompose-nl/status` 只返回配置可用性及错误说明，不请求模型，不泄露 Key 或完整服务配置。未配置不影响服务启动和规则分解。
- 后端模型请求默认 45 秒超时，前端 AI 请求单独使用 60 秒；现有其他接口超时不变。停止等待、切换入口或关闭对话框时取消请求，迟到响应不能覆盖当前页面状态。不自动重试付费模型请求。
- 模型返回内容只作为 JSON 数据解析，不执行模型生成的代码或工具调用。输出结构不符合约定时明确报错，不悄悄交给规则分解器尝试处理。
- 自然语言输入上限为 UTF-8 200KB。模型原始响应另外限制大小，最终画布仍为最多 100 节点、200 边。
- 模型任务仍是模拟任务，输出变量只遵循既有成功写入 `true` 的语义，不引入真实认证、网页跳转、代码部署或业务 HTTP 执行能力。
- 自动化使用注入的模型响应替身，不依赖真实密钥或外网。真实服务可用性必须另行验收，不能由替身测试结果推断。
