# 可视化任务编排器课堂演示流程

配套讲义为 `演示讲义.pptx`，共 6 页。现场演示计划为 **7 分 30 秒**，测试结果以 `测试报告.md` 和当次 `npm test` 输出为准。以下是演示步骤及预期结果，不代表所有人工项目已经完成验收。

## 演示前准备

1. 按根目录 README 安装依赖并启动服务。后端使用 3000 端口，前端使用 5173 端口。
2. 打开编辑器和 `examples/login-spec.md`。浏览器建议使用 Chrome / Edge，窗口至少 1280 × 720。
3. 运行 `npm test` 和前端构建，保留终端结果。把测试报告、演示讲义和原始附录 JSON 放在便于切换的位置。
4. 检查前端能访问后端。离线演示需在断网前完成依赖安装，程序运行本身不依赖外部服务。
5. 从示例载入正常方案，确认 `failRate=0`、“失败后继续”关闭、默认并发为 3。首次演示可从空画布开始。

| 时间 | 操作 | 预期结果与验收点 |
| --- | --- | --- |
| 00:00–00:35 | 介绍课程范围与架构，展示五区编辑器 | 规则分解、DAG 编排、模拟执行、文件保存。前端与引擎解耦。 |
| 00:35–02:10 | 导入规格，填入或粘贴登录示例，开始分解。修改一个任务名称，观察依赖、并行组和分支列，确认生成 | 识别为 Markdown。9 条 TaskSpec 与附录 6.5 一致。运行图为 11 节点、12 条边。对应 AC-01、AC-02。 |
| 02:10–03:20 | 拖入延时节点，尝试非法连线，删除该节点并撤销、重做，最后恢复示例 | 5 类节点可创建。自环、重复边、开始二出、条件三出应提示具体原因。对应 AC-03、AC-04。 |

## 演示时需要解释的规则

**示例节点数修订。** 说明书 4.4 和 AC-04 规定 start 只有一条出边，但 6.2 与附录 A 的原始图直接从 start 分出两条边。用户确认严格执行 start 一出。运行版增加一个普通 `task` 分发并行任务，耗时 0ms，因此运行图为 11 节点、12 条边。节点类型仍然只有五类，9 条原始 TaskSpec 不变。原始 10 节点、11 边 JSON 仅用于对照。

**默认条件结果。** `比对密码哈希` 成功后输出 `passed=true`。条件表达式为 `passed == true`。本产品模拟成功与失败，不处理真实账号密码，也不连接登录服务。

**跳过与失败不同。** 条件未激活分支跳过到汇聚点。失败耗尽则阻止依赖链继续执行，默认继续传播跳过。“失败后继续”允许忽略上游失败，但不会把失败节点改成成功。

**两层校验。** 前端在操作时拒绝常见非法连线。服务端执行前仍运行 R1–R8 全量校验，客户端绕过 UI 也不能执行非法图。

**状态更新。** 前端每 500ms 查询增量日志与完整节点状态。六种状态的颜色与图例共用常量。执行完成后进度为定态节点数除以总节点数，跳过与取消也属于定态。

## 补充人工核对步骤

主流程无法在有限时间内逐一演示所有边界时，可在课前执行并登记实际结果。

| 项目 | 操作 | 预期 |
| --- | --- | --- |
| AC-01 边界 | 空文本、超 200KB 文件、无标题编号的纯文本、重复编号、孤立分支后缀 | 友好报错，解析错误码为 40003，不生成误导性任务清单。英文 Markdown 可以正常识别。 |
| AC-02 编辑一致性 | 改名、改类型、增删任务、取消勾选中间任务或一个分支任务 | 最新清单生成画布，省略节点的依赖得到回溯。缺失条件分支或非法依赖应明确提示。 |
| AC-03 五类节点 | 分别拖入 start、task、condition、delay、end，编辑允许的属性，撤销、重做 | 画布与属性同步，已有 start/end 时不能再次创建同类唯一节点。 |
| AC-05 服务端拒绝 | 复制一个合法方案 JSON，添加反向依赖形成环，保存后请求执行 | 40002，details 包含 R2 与环上 nodeId，没有节点开始执行。参考 `tests/api.test.js` 与 `tests/validator.test.js` 中实际用例。 |
| AC-06 两侧路由 | 分别将条件设为 `true` 与 `false` 执行 | 两侧分别激活，另一侧跳过，汇聚节点最终执行。 |
| AC-07 停止 | 创建较长耗时的任务并执行，然后停止 | 运行 CANCELED，未开始节点 CANCELED。 |
| AC-08 实时观察 | 记录执行期间日志事件、节点颜色与图例计数，检查浏览器控制台 | 状态对应一致，轮询周期 500ms，控制台无应用错误。 |
| AC-09 损坏文件 | 导入缺字段或非法版本 JSON，重启后端再打开已存方案 | 损坏输入友好报错，已保存方案可继续读取。 |
| 离线运行 | 依赖安装后断开外网，保留本机网络，重复导入、执行、保存、刷新 | 不需要外部服务，全流程可操作。不要把“首次联网安装依赖”与“离线运行”混为一谈。 |

## 演示收尾

恢复正常示例，确保 `failRate=0`，保存最终方案。报告中记录实际运行日期、测试命令、环境与人工验收结果，不把“预期结果”标成“已通过”。若出现与预期不同的行为，保留对应方案 JSON、runId、日志与复现步骤。
