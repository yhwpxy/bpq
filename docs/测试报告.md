## 性能与离线验证

50KB级方案，真实 HTTP 保存/加载各10次，本机实测：

| 操作 | 最小 | 平均 | 最大 | 门槛 |
| --- | ---: | ---: | ---: | ---: |
| 保存 | 14.40ms | 19.42ms | 42.74ms | ≤500ms |
| 加载 | 1.08ms | 1.40ms | 2.67ms | ≤500ms |

浏览器主流程通过路由拦截禁止外部请求，只放行 localhost/127.0.0.1，仍可分解、生成、执行、保存和重开；捕获到的外部请求数为0。此验证模拟断外网，未变更电脑网络设置。首次npm安装与浏览器安装仍需要网络。

## 复核中发现并已修复的问题

| 问题 | 修复与回归 |
| --- | --- |
| 取消整条分支后标签丢失 | 依赖回溯携带true/false信号，直连join仍合法，单元+浏览器回归 |
| 中文章内小数编号冲突 | 保留局部编号层级，补混合编号和Markdown小数列表用例 |
| 条件两侧末节点未对齐 | 在安全拓扑层内移动前驱，同层重新排布，无重叠断言 |
| 旧轮询请求阻塞新运行 | epoch隔离请求与定时器，旧回包不覆盖新状态 |
| X6探测端口误弹Toast | 探测阶段静默，鼠标实际命中非法端口再提示，真实拖线回归 |
| 方案ID与index.json碰撞 | 拒绝大小写index保留名称，不损坏已有索引 |
| 终态可见早于快照落盘 | 终态查询等待最终原子写完成，跨实例读取回归 |
| 框选拖动后仅保存一个节点 | 同步所有节点位置，画布/草稿保持一致 |

引擎/存储、前端与共享转换模块经过非作者代理交叉复核。没有未处理的阻断问题。首次开发期间浏览器热更新曾使测试页面重新挂载；最终回归在源码冻结后执行。

## 边界与未宣称事项

- 原始附录图因start二出不能通过严格校验，属于已确认的规格冲突修订。
- 只在Chrome自动验证；Edge最新两版与真实多人局域网环境未逐一实机验证。
- 100节点/200边限制由Schema与UI执行。自动化验证基本布局与交互，不等同于跨设备帧率基准。
- 进程重启标记未完成运行中断，不从中途恢复计时器。
- 使用公开npm依赖，整个运行链路没有真实外部任务调用。
